# نظام التحقق من أصالة المنتج للمحلات التجارية

نظام متكامل مكون من:
1. **صفحة الهبوط (`index.html`)**: الصفحة التي تفتح على هاتف الزبون بمجرد مسح الكود.
2. **أداة طباعة الملصقات (`print-qr-sticker.html`)**: لتوليد وطباعة استيكرات الـ QR وتوزيعها على المنتجات داخل المحل.

---

## 1. صفحة الهبوط (`index.html`)
- تفتح مباشرة وسريعة جداً ومخصصة للهواتف الذكية.
- حركة علامة صح خضراء ناعمة فور الفتح (SVG Animated Checkmark).
- عنوان صريح وواضح: **"هذا المنتج أصلي 100%"**.
- رسالة طمأنة وتأكيد جودة رسمية معتمدة بدون أي تعقيد أو أرقام تسلسلية.
- مؤثرات بصرية راقية مع تناثر أوراق احتفالية (Confetti) لإعطاء انطباع رسمي وفاخر.

## 2. أداة ملصقات الـ QR (`print-qr-sticker.html`)
- تتيح لك وضع رابط موقعك لإنشاء كود QR موحد لكل منتجات المحل.
- زر **تحميل الملصق صورة عالية الدقة (PNG)** جاهزة للطباعة كاستيكر لاصق.
- زر **طباعة صفحة ملصقات كاملة (A4)** لطباعة ورقة كاملة تضم استيكرات متعددة جاهزة للقص واللصق على المنتجات.
